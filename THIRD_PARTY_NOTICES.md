## Google Gemini API

The API sends prompts to Google Gemini using the Generative Language API. Review Google's current API terms, privacy documentation, model availability, and billing requirements before deploying:

- https://ai.google.dev/gemini-api/docs
- https://ai.google.dev/gemini-api/terms

## Open-Meteo

Current weather and geocoding data come from Open-Meteo:

- https://open-meteo.com/
- https://open-meteo.com/en/license

The application uses Open-Meteo's public API as an upstream service. Check its current attribution and usage requirements before operating a public production service.

Package licenses and notices are available from each package's NuGet page. The application uses standard .NET, ASP.NET Core, Entity Framework Core, Npgsql, Redis caching, DotNetEnv, and xUnit packages.
