Why this project exists

An API you can understand before you extend it.

This page is the map. Swagger is the control panel. The API response is the contract your frontend, mobile app, or another service can use.

01

Authentication

Create an account and receive a JWT access token. Protected routes use that token to keep each user's history separate.

02

AI with guardrails

Gemini is asked for one predictable JSON shape. The server parses and validates it before returning anything to the client.

03

Fast repeat requests

Redis caches the same user, city, question, and model combination for ten minutes. PostgreSQL keeps an activity record.
